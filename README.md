## About the Application

1Password 10 brings password and vault management to the Windows desktop, giving users a single place to arrange, find, and use their saved entries. Its workflow is built around a familiar desktop application experience.

The release uses encrypted local storage and is intended for users who want quick lookups, data import and export, and configurable access behavior. Additional desktop conveniences include one-click filling, automatic locking, dark mode, and support for secure backups.

## Key Capabilities

- Store vault contents in an encrypted local password database

- Import and export data between different setups
- Automatically lock sessions according to the configured behavior
- Switch to dark mode for a different desktop appearance

- Handle secure backups of vault data

## Everyday Use

A standard session can be completed as follows:

1. Start the application and unlock the vault.
2. Search for a login, note, or another saved item.
3. Apply one-click fill while signing in to supported websites or applications.
4. Create additional entries and arrange them within vaults.
5. Export information when creating an external copy or moving to another setup.

Keeping vaults organized makes items easier to locate. You can also adjust the auto-lock interval to match the way you use your computer.

---

## Settings and Data Handling

Configuration is performed within the Windows application. Available controls include vault access behavior, display preferences like dark mode, and the auto-lock interval.

For migration or backup work, store exported files in a separate folder. This keeps them easier to locate when they are needed later.
